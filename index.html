NPA IM Migration System

Copy records from a source feature layer to a target layer: map fields, filter, match, overwrite, append, attachments, pictures and related tables.

2Map the fields

Each row is a field in the target layer. Choose where its data comes from. Suggested matches are marked; fields with a value list get a value mapping below the row.

3Set the rules

Which source records to copy

Add conditions such as status equals submitted. With no conditions, every record is copied.

Records already in the target

Choose which target field must equal which source field for a record to count as the same, for example target tmp_globalid = source globalid. Matching records are skipped unless the overwrite rule applies.

Attachments

For records already in the target (uses the match fields above). Only target records with no attachments are filled.

Pictures into a repeat

For pictures taken several at a time in one question of the source (multiline) that must become records of a repeat in the target: one repeat record per picture, linked to its parent, with the picture attached.
Fill the repeat fields: values can come from the picture (file name, number…), from the parent source record, or be fixed.
For records already in the target (uses the match fields above) that have no repeat records yet.

Related tables

Also copy related records (for example a Survey123 repeat, or another table linked by parentglobalid) together with their parent records, each with its own field mapping. A table can also be the child of an earlier related table.

Mark source records as sent

For example, change status from submitted to sent so the same records are not copied again. Only records the target accepted are updated. You need edit rights on the source layer.
